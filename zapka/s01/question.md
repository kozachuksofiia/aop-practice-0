Алгоритм — це послідовність кроків для розв’язання задачі. Програма — це код, який реалізує один або кілька алгоритмів і який може виконати комп’ютер.
Мови програмування потрібні, щоб нам було легше писати команди для пк. Наприклад ми пишемо 1+3, а спеціальна програма в нашому випадку JAVA перекладає цей запис у команду, який процесор може виконати.
Сам по собі комп'ютер не може зробити що йому не вказували.
